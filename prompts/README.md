# Prompts

Vacío intencionalmente durante la fase Foundation.

Esta carpeta contendrá las plantillas de prompts de IA (texto plano,
Markdown o Jinja) usadas por los agentes Writer, SEO, Social y AI
Orchestrator, a partir de docs/ROADMAP.md Fase 2.

Se mantienen separadas del código Python a propósito, para que el equipo
editorial pueda revisar y ajustar el tono/estilo de los prompts sin
necesidad de tocar la aplicación.

Convención sugerida cuando se agreguen: un archivo por agente/propósito,
por ejemplo `writer_rewrite.md`, `seo_metadata.md`, `social_copy.md`.
